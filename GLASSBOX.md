# Glassbox

Glassbox is the visual layer for the PAIRLAB experiments.

Core idea:

> Never regenerate the world. Mutate the state.

The roadmap is expected to have a normal IF path and explicit ELSE branches for deviations. The visual layer renders workflow state; it does not become workflow authority.

PAIRLAB is the execution/governance experiment. Glassbox is the observation/visualization experiment. They may evolve together, but remain separate concerns.
